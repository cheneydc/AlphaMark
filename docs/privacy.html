Privacy Policy

Last updated: May 29, 2026

AlphaMark is a Chrome extension that helps you organize your bookmarks using AI. We do not collect, store, or transmit any personal data. NO DATA COLLECTION

Data Processing

All bookmark data, browsing history, and configuration settings are processed locally within your browser using Chrome's built-in APIs:

  • chrome.bookmarks — Read and organize your bookmark tree. Data never leaves your browser.
  • chrome.storage — Save your preferences (AI config, categories, analysis results). All stored locally.
  • chrome.history — Aggregate visit frequency to improve classification accuracy. Processed locally only.
  • chrome.tabs — Read current tab URL/title when you bookmark a new page, to suggest a category.

LLM / AI Analysis

If you enable AI-powered classification, page content may be sent to the LLM API endpoint you configure (e.g., OpenAI, Gemini, or a custom endpoint).

  • You must provide your own API key — AlphaMark does not provide or manage any API keys.
  • The API endpoint is fully configurable. You choose which provider to use.
  • AlphaMark does not have access to the data sent to or received from the LLM API.
  • AI analysis is optional and disabled by default.

Network Access

Host permissions are required solely to fetch page HTML content for LLM analysis. No data is sent to any server other than the LLM endpoint you explicitly configure.

Third-Party Services

AlphaMark does not use any analytics, tracking, telemetry, or third-party data collection services of any kind.

Data Storage

  • Config & results: Stored in chrome.storage.local and chrome.storage.sync. Remains on your device.
  • Bookmark backup: Exported JSON files are saved to your local machine via browser download — never uploaded anywhere.
  • Uninstall: When you uninstall the extension, all local data is automatically removed by Chrome.

Contact

If you have any questions about this privacy policy, please open an issue on GitHub or contact us at cheneydc@gmail.com.

隐私政策

更新日期：2026 年 5 月 29 日

AlphaMark 是一款帮助您使用 AI 整理书签的 Chrome 扩展程序。我们不会收集、存储或传输任何个人数据。 不收集数据

数据处理方式

所有书签数据、浏览历史记录和配置设置均在您的浏览器本地处理，仅使用 Chrome 内置 API：

  • chrome.bookmarks — 读取和整理您的书签树。数据不会离开您的浏览器。
  • chrome.storage — 保存您的偏好设置（AI 配置、分类、分析结果）。全部存储在本地。
  • chrome.history — 聚合访问频率以提高分类准确率。仅在本地处理。
  • chrome.tabs — 新增书签时读取当前标签页 URL 和标题，用于推荐分类。

LLM / AI 分析

如果您启用 AI 分类功能，网页内容可能会被发送到您配置的 LLM API 地址（例如 OpenAI、Gemini 或自定义端点）。

  • 您必须提供自己的 API Key — AlphaMark 不提供也不管理任何 API Key。
  • API 端点完全可配置，您自行选择使用的供应商。
  • AlphaMark 无法访问发送到 LLM API 或从 LLM API 接收的数据。
  • AI 分析为可选功能，默认关闭。

网络访问

主机权限仅用于获取网页 HTML 内容以供 LLM 分析。除您明确配置的 LLM 端点外，不会向任何服务器发送数据。

第三方服务

AlphaMark 不使用任何分析、跟踪、遥测或第三方数据收集服务。

数据存储

  • 配置和分析结果：存储在 chrome.storage.local 和 chrome.storage.sync 中，保留在您的设备上。
  • 书签备份：导出的 JSON 文件通过浏览器下载保存到您的本地电脑 — 不会上传到任何地方。
  • 卸载：卸载扩展程序后，Chrome 会自动清除所有本地数据。

联系方式
